# Start Here

## Welcome to the Data Analytics Fellowship GitBook

This GitBook is your guide to the fellowship. For every module, it tells you what you'll learn, why it matters for a data job, and what to read each day.

You'll learn new material in **interactive readings**, which open on their own pages. This GitBook helps you get ready before each reading, and helps you review and connect ideas after it.

## How the fellowship is organized

The fellowship is made of **modules**. Each module teaches one big area, like Python or data analysis. Every module has the same pages, in the same order:

| Page | What it's for |
| --- | --- |
| **Overview (Read FIRST)** | Your map of the module: the pages in order, the new tools, and the skills |
| **Introduction** | What you already know, what you'll learn, and why it matters at work |
| **Quests** | One page for each day's reading |
| **Checkpoint** | Review and practice before the project |
| **Conclusion** | What you can do now, and where these skills show up next |
| **Boss Battle (Module Project)** | A project where you use every skill from the module. Your instructor shares the details. |

## About the game words

You'll see a few words from games, like **Quest** and **Boss Battle**. They help you see your progress. Each one always comes with its plain meaning:

| Game word | What it means |
| --- | --- |
| **Quest** | One day's reading: a GitBook page plus the interactive reading it links to |
| **Checkpoint** | Review and practice before the project |
| **Boss Battle** | The Module Project |
