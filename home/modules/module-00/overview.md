# Overview of Module 0: Foundations (Read FIRST)

**Time:** about 5 minutes

Read this page before anything else in Module 0. It's your map: what the module is about, the order of the pages, the new tools, and where you'll practice each skill. Come back to it whenever you want to see where you are.

## What this module is about

This module sets up the tools and habits every analyst uses. You'll learn to tell what kind of data you have, use the terminal, save your work with Git, and check what an AI tells you. At the end, the [Boss Battle (Module Project)](introduction.md#the-boss-battle-module-project) asks you to use all four on a real dataset you've never seen.

## New tools this module

A **tool** is anything analysts use to get work done. This module has two kinds:

* **Software** is a program you open and use, like the Terminal app or Git.
* A **website** is something you open in a browser, like GitHub.

| Tool | Kind | What it does | Introduced in |
| --- | --- | --- | --- |
| **Terminal** | Software (the window) | Lets you type commands to your computer | [Module 0 Introduction](introduction.md#the-terminal-and-the-shell) and [Quest 0.2](quest-02-terminal.md#new-tool-terminal) |
| **zsh** | Software (the shell inside Terminal) | Reads your commands and runs them | [Module 0 Introduction](introduction.md#bash-and-zsh-two-shells) |
| **Git** | Software | Saves every step of your work on your computer | [Quest 0.3](quest-03-git.md#new-tool-git) |
| **GitHub** | Website | Stores your Git history online, so others can see it | [Quest 0.3](quest-03-git.md#new-tool-github) |

## How each quest page works

Every quest page has the same sections, in the same order. At the top, you'll see the total time and the part of your analyst toolkit you're working on. The total time counts both the GitBook page and the interactive reading.

1. **Introduction**: an example, what you'll learn, the main takeaway, and why it matters at work
2. **Learning goals**: a checklist of what you'll be able to do
3. **Quick recall**: something you already know that this reading builds on
4. **New tool** (only when there is one): what it's for, how you'll see it, and where to learn more
5. **Words to know**: the new terms, in plain words
6. **Before you read**: a question to think about first
7. **Read**: what to look for, then the link to the interactive reading
8. **Main takeaways**: a summary, common mix-ups, and how it connects to the next reading and the Boss Battle (Module Project)
9. **Quick check**: two questions to test yourself

Submit each reading for credit when you finish it.
