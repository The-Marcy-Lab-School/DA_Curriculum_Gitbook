# ⚡ Checkpoint: Trace Before Run

Don't run this code yet.

```python
for number in range(1, 5):
    if number % 2 == 0:
        print(number)
```

Write the **exact output**.

### First Attempt

Trace it without Python.

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

Trace one value at a time.

For each value, ask:

1. What is `number`?
2. Is `number % 2 == 0` True or False?
3. Does `print()` execute?

</details>

### Second Attempt

Try again before revealing the Answer.

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

The output is:

```text
2
4
```

The Loop considers `1`, `2`, `3`, and `4`.

Only `2` and `4` make the Conditional evaluate to True, so only those values reach `print()`.

</details>

# 🐛 Bug Hunt: Off by One

A programmer wants to process five positions:

```text
0, 1, 2, 3, 4
```

They write:

```python
for index in range(4):
    print(index)
```

**What's wrong?**

Be precise. Don't stop at:

> “The Loop is wrong.”

Name what the code actually does and how that differs from the intended behavior.

### First Attempt

Write the values generated by `range(4)`.

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

Does `range(4)` include `4`?

Remember that the stop value in `range()` is not included.

</details>

### Second Attempt

Now name the bug.

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

`range(4)` produces:

```text
0, 1, 2, 3
```

It does **not** include `4`.

If the goal is to process positions `0` through `4`, this Loop stops one iteration too early.

This is an **Off-by-One Error**.

A correction would be:

```python
for index in range(5):
    print(index)
```

</details>

# 🧠 Nested Logic Check

Consider this code:

```python
for row in range(2):
    for column in range(2):
        print(row, column)
```

Before running it, answer:

**How many times does `print()` execute?**

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

For each value of `row`, the Inner Loop completes all of its iterations.

Trace:

**Outer Iteration → Inner Iterations → Next Outer Iteration**

</details>

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

`print()` executes **4 times**.

The pairs are:

```text
0 0
0 1
1 0
1 1
```

There are 2 Outer Loop iterations.

For each one, there are 2 Inner Loop iterations.

So the Inner Loop body executes:

**2 × 2 = 4 times**

</details>

# 💼 Interview Arena

> **How do you trace a Loop with a Conditional without running the code?**

<details>
<summary>💡 Hint — Open If You're Stuck</summary>

Think about three things:

**Current Value → Condition → Result**

</details>

<details>
<summary>✅ Example Answer — Open After You've Answered</summary>

I trace the Loop one iteration at a time. I write down the current value of the Loop variable, evaluate the Conditional using that value, and record what the code does before moving to the next iteration.

For nested logic, I also track which Outer Loop iteration I'm currently inside.

This helps me predict the exact behavior and makes edge cases like Off-by-One Errors easier to identify.

</details>
