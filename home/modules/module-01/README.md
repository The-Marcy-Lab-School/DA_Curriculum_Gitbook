## Programming Fundamentals: Control Flow, Functions, OOP & Complexity

### 🎯 Mission: Make Python Do the Work

Module 0 gave you the habits for working carefully.

Now you'll start writing real Python programs.

In this module, you'll learn how to make programs **choose, repeat, organize work into functions, validate input, represent objects, compare approaches, and recover when code doesn't behave the way you expected**.

You're not learning syntax just to memorize syntax.

You're learning to reason about what code will do.

---

## 🧭 Your Quest Map

### Quest 1.1 — Trace the Path (Days 1–2)

Trace Conditionals, Loops, and Nested Control Flow before running the code.

### Quest 1.2 — Build It Once, Use It Again (Days 3–5)

Use Functions, Parameters, Return Values, and Scope to organize reusable work.

### Quest 1.3 — When the Crowd Grows (Day 6)

Build your first intuition for how an approach changes as the amount of data grows.

### Quest 1.4 — Pick the Right Container (Day 7)

Compare Python Data Structures and choose structures that fit the job.

### Quest 1.5 — Make It Survive (Day 8)

Learn why data is Serialized into formats such as JSON, CSV, and TXT.

### Quest 1.6 — Validate, Catch, Keep Going (Days 9–10)

Validate incoming data and handle errors without letting one bad input destroy the entire program.

### Quest 1.7 — One Job at a Time (Days 11–12)

Build another Function with less scaffolding and reconnect Functions, Validation, Error Handling, and Serialization.

### Quest 1.8 — Meet the Objects (Days 13–15)

Build Classes and independent Objects, then practice `__init__`, `__str__`, and `__repr__`.

### Quest 1.9 — Lookups Matter (Days 16–17)

Compare Linear Search with Dictionary Lookup and connect Big-O to real code.

### Quest 1.10 — Looks Right. Is It? (Days 18–19)

Debug code systematically and prove that code running isn't the same thing as code being correct.

## 🏆 Your Final Mission

During Days 20–24, you'll build a plain-Python **Inventory Tracker**.

Your program will need to process transactions, validate input, use an `Item` class, update inventory, survive malformed data, report low-stock items, and explain the tradeoff between Linear Search and Dictionary Lookup.

The Boss Battle asks you to combine the skills.

The quests prepare you to make the decisions.
