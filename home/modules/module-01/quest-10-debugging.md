# 🐛 Bug Hunt 1: Off by One

The program should process five indexes:

```text id="7bcrch"
0, 1, 2, 3, 4
```

It uses:

```python id="f2c6zz"
for index in range(4):
    process(index)
```

Name the bug precisely.

Don't answer:

> “The Loop is broken.”

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

Write out exactly what `range(4)` produces.

Then compare:

**Expected Values ↔ Actual Values**

</details>

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

This is an **Off-by-One Error**.

`range(4)` produces:

```text id="d1h5qq"
0, 1, 2, 3
```

The expected index `4` is never processed.

The code runs, but the Loop boundary causes it to perform one fewer iteration than required.

</details>

# 🐛 Bug Hunt 2: Scope / Return

Consider:

```python id="uqzhsv"
def calculate_total(values):
    total = 0

    for value in values:
        total += value

    return value
```

The programmer intended to return the total.

The Function runs.

What's wrong?

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

Compare:

**Value being accumulated**

with:

**Value being returned**

</details>

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

The Function accumulates the result in:

```python id="p7e8ls"
total
```

but returns:

```python id="g4gb3q"
value
```

So it returns the final Loop value instead of the accumulated total.

The intended line is:

```python id="uyizre"
return total
```

This is a Logic Error involving the wrong variable being returned.

Again, valid syntax doesn't prove correct logic.

</details>

# 🐛 Bug Hunt 3: Undefined Attribute

Consider:

```python id="0a90jg"
class Item:
    def __init__(self, name, quantity):
        self.name = name
        self.quantity = quantity

    def is_low_stock(self):
        return self.stock < 5
```

The Method expects to check an Item's Quantity.

What's wrong?

<details>
<summary>💡 Hint — Open After Your First Attempt</summary>

Compare the Attribute created in `__init__` with the Attribute used inside `is_low_stock()`.

</details>

<details>
<summary>✅ Answer — Open After Your Second Attempt</summary>

`__init__` creates:

```python id="3mtdhl"
self.quantity
```

but the Method tries to use:

```python id="s04l70"
self.stock
```

`self.stock` was never created.

This is an **Undefined Attribute** problem.

A likely correction is:

```python id="lnjszw"
return self.quantity < 5
```

The debugging move is to compare:

**Attribute Expected → Attribute Actually Defined**

</details>

# 🔧 Refactor Check

Debugging isn't only about repairing broken behavior.

Sometimes your code works, but you discover the same logic repeated in several places.

For example:

```python id="7sgunr"
if quantity < 0:
    print("Invalid quantity")
```

appears again and again throughout a program.

Ask:

> **Should this responsibility become a reusable Function?**

That's a **Refactoring** question.

Refactoring changes the organization or structure of code while preserving its intended behavior.
