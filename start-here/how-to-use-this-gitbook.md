# How to Use This GitBook

Each module is organized into a sequence of quests.

A quest may ask you to:

1. understand why a skill matters,
2. retrieve important technical vocabulary,
3. make a prediction,
4. launch an interactive reading,
5. return for a checkpoint,
6. apply what you learned,
7. explain the skill like an emerging data professional.

When you're ready, begin Module 0.
